## 🤟 TALS — The Project That Changed Everything

> *In 2011, I watched a deaf person struggling to communicate in a world that wasn't built for them.  
> I decided to build the bridge.*

**TALS** (Traductor Autónomo de Lengua de Señas) is a real-time Autonomous Sign Language Translator
using computer vision, gesture recognition ML, and embedded hardware (Raspberry Pi).

| 🗓️ Year | 🏅 Milestone |
|:---:|---|
| 2011 | 💡 Idea conceived after witnessing deaf person excluded from everyday conversation |
| 2017 | 🥇 Top 6 national projects in Chile — only foreign team outside the capital |
| 2017 | 🎯 Semifinalist SAP Innomarathon Chile · Selected Latinomics Leadership Summit Vienna |
| 2018 | 💰 **Won CORFO Capital Semilla — 33,000,000 CLP (~USD 50,000)** |
| 2018 | 🌏 **Represented Chile at Computex Taipei 2018** (Taiwan) via ProChile |
| 2018 | 🎯 Semifinalist SAP Innomarathon 2018 |
| 2019 | 📺 Featured on CNN Chile in national news report |
